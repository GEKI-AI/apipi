# Review

Read-only. Follow `CONTRIBUTING.md` Reviewing a PR.

Read `gh pr diff`, the linked issue if any, and the spec paths.

Answer those five questions. Verdict: `Approve` or `Must fix`.

Must fix = a missed goal, spec and code disagree, or a broken rule.
Small style notes do not block unless they break a spec.

Do not edit files. Do not push. Do not merge.
