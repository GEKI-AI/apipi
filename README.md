# ApiPi

**This project is discontinued and no longer maintained.**

ApiPi was an open-source agent gateway with an HTTP API compatible with
the OpenAI Agents API, running [Pi](https://pi.dev) in Firecracker
microVMs. Development has stopped. The repository is archived and kept
read-only for reference. Published versions on PyPI (`geki-apipi`) stay
available, but receive no fixes.
